# Satya — 90-second walkthrough

For showing the project to a recruiter or interviewer. Open <https://aj-demos.pages.dev/satya/> before you start; it loads instantly on a recorded run.

| Time    | Show                                                                                      | Say                                                                                                                                                                                                                                                      |
| ------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–10 s  | The Desk, opened on a recorded run                                                        | "Satya checks the facts in a text. It splits the text into single claims and gives each one a cited verdict, or abstains when the evidence is thin."                                                                                                     |
| 10–25 s | Pick **A news paragraph with one wrong number** in _Recorded runs_                        | "Two claims check out. The third, a launch date, is underlined as refuted, and the margin shows each verdict with its confidence."                                                                                                                       |
| 25–45 s | Click the refuted claim → **Evidence**, then **Debate**                                   | "Evidence comes from Wikipedia and the web. Retrieval is hybrid: BM25 and dense embeddings are fused with reciprocal rank fusion, then a cross-encoder re-ranks the passages. An advocate and a skeptic argue for two rounds and have to cite passages." |
| 45–55 s | **Verdict** tab, then **Trace**                                                           | "Three judges vote, and confidence combines their agreement with the re-ranker score. Trace lists every model call with its tokens and latency. Each call is a durable step in a Cloudflare Workflow."                                                   |
| 55–70 s | Paste a short text, press **Check facts** (or explain the capacity notice if it is shown) | "Live checks run on free tiers: gpt-oss-120b on Workers AI, with the same model on Groq as a fallback, pinned per run. When the day's budget is used, the demo falls back to recorded runs. It never breaks."                                            |
| 70–80 s | **Benchmarks**                                                                            | "The same TypeScript pipeline runs on my laptop with Qwen3-4B in 6 GB of VRAM, against SciFact, FEVER and HoVer baselines: LLM-only, single-agent RAG, and Satya with and without debate. Every number is generated, none is typed in."                  |
| 80–90 s | **How it's built** (flowchart, architecture), then the MCP card on the Desk               | "The evidence tools are also a public MCP server, so any assistant can use them. Code, tests and the QA report are on GitHub."                                                                                                                           |

**If a live check is slow:** it takes about 30–60 s. Keep talking over the status line ("Splitting claims · Finding evidence · Debating · Judging — step n of ~N"), or switch back to a recorded run.
